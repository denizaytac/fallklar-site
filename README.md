# Fallklar

Landingpage für **Fallklar** – die intelligente Zwischenschicht für eingehende Anrufe.

Fallklar übernimmt in klar definierten Situationen, zum Beispiel nach Feierabend, im Bereitschaftsdienst oder bei Nichtannahme. Der Dienst versteht das Anliegen, erfasst die relevanten Angaben, unterscheidet dringende Fälle von Anliegen, die warten können, und eskaliert nur nach den Regeln des Unternehmens.

Die Website wird über GitHub Pages veröffentlicht. Die produktive Seite liegt in `index.html`.
